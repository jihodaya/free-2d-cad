Free 2D CAD 사용자 글꼴 폴더
==========================
■ TrueType 글꼴 (*.ttf, *.otf, *.ttc)
- 이 폴더에 넣으면 Windows에 설치하지 않아도 도면 문자에 쓰이고, 문자 스타일 글꼴 목록 맨 위에 ★로 나옵니다.

■ SHX 선 글꼴 (*.shx) — romans.shx, simplex.shx, whgtxt.shx(한글 큰 글꼴) 등 도면용 선 글꼴
- SHX 글꼴은 각 제작사 저작물이라 배포본에 넣지 않았습니다. 가지고 있는 .shx를 이 폴더나 SHX 하위 폴더에 넣으면 찾습니다.
- 같은 이름의 .shx 파일이 있으면 원래 선 모양 그대로 그립니다 (일반 shapes, 유니코드 unifont, 2바이트 bigfont 모두 지원).
- 파일이 없으면 fontmap.txt 대응표 → 옵션(OPTIONS)의 '대체 글꼴'(기본 romans.shx, 한글 whgtxt.shx) 순으로 대신 그립니다.
  기본 대체도 SHX라 글자 폭과 배치가 원본과 같습니다.
- TrueType으로 보고 싶으면 fontmap.txt에 "원래이름.shx=글꼴.ttf"를 적거나 옵션의 대체 글꼴을 .ttf로 고릅니다.
- SHX 글꼴 파일은 각 제작사의 저작물입니다. 라이선스를 확인하고 쓰세요.

■ 넣거나 바꾼 뒤 Free 2D CAD를 다시 실행하면 적용됩니다.
