이 폴더의 해치 패턴 파일(*.pat)은 Free 2D CAD 해치 창의 패턴 목록에 나옵니다.
- 기본 패턴 47종(ANSI31~38, ISO02~15, 벽돌·육각형·흙·콘크리트 등)은 프로그램에 내장되어 있습니다(직접 정의, mm).
- 그 밖에 넣은 *.pat 파일은 "사용자" 탭에 나옵니다. 파일 이름과 개수는 제한 없습니다.
- 가지고 있는 *.pat(다른 CAD 프로그램의 패턴 파일, 회사 표준 패턴)를 넣으면 '사용자' 탭에 나오고, 내장 패턴과 이름이 같으면 넣은 파일의 정의로 그립니다.
- 넣은 뒤 Free 2D CAD를 다시 실행하면 적용됩니다.
- Free 2D CAD 폴더째 복사하면 패턴도 같이 옮겨집니다.
