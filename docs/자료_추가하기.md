# 빠진 자료 채워 넣기 (글꼴·해치 패턴·선종류·템플릿)

Free 2D CAD에는 **재배포가 허용된 것만** 들어 있습니다. 다른 회사의 저작물인 SHX 글꼴, 다른 CAD 프로그램의 해치 패턴·선종류 파일은 넣지 않았습니다.
그 대신 **가지고 있는 파일을 정해진 폴더에 넣기만 하면** 그대로 쓰입니다. 설치나 설정은 필요 없습니다.

## 폴더 위치

모든 폴더는 **`Free2DCad.exe`가 있는 폴더 안**에 있습니다. 처음 실행하면 자동으로 만들어지고, 폴더마다 사용법 `README.txt`가 들어 있습니다.
프로그램 안에서는 **도구 > 사용자 폴더 열기**로 바로 열 수 있습니다.

```text
Free2DCad\
├─ Free2DCad.exe
├─ Fonts\        ← 글꼴 (TTF·OTF·TTC), fontmap.txt
│  └─ SHX\       ← SHX 선 글꼴
├─ Patterns\     ← 해치 패턴 (*.pat)
├─ Linetypes\    ← 선종류 (*.lin)
├─ Templates\    ← 새 도면 템플릿 (*.dwg, *.dwt, *.dxf)
└─ Blocks\       ← 블록 라이브러리 (*.dwg)
```

파일을 넣은 뒤 **Free 2D CAD를 다시 실행**하면 적용됩니다. 템플릿만은 '새로 만들기'를 누를 때마다 다시 찾습니다.

## 무엇을 어디에 넣나

| 빠진 것 | 넣을 파일 (예) | 넣을 곳 | 넣으면 달라지는 점 | 넣지 않으면 |
| :--- | :--- | :--- | :--- | :--- |
| **SHX 선 글꼴** | `romans.shx`, `simplex.shx`, `txt.shx`, `isocp.shx`, 한글 큰 글꼴 `whgtxt.shx`·`ghs.shx` 등 | `Fonts\SHX\` | 도면 문자가 원래 CAD와 **같은 모양·같은 글자 폭**으로 그려집니다 | TrueType 글꼴(맑은 고딕 등)로 대신 그립니다. 읽는 데는 문제없지만 글자 폭과 줄 끝 위치가 조금 다를 수 있습니다 |
| **TrueType 글꼴** | 회사 표준 `*.ttf` | `Fonts\` | Windows에 설치하지 않아도 도면 문자에 쓰이고, 문자 스타일 목록 맨 위에 ★로 나옵니다 | Windows에 설치된 글꼴과 함께 들어 있는 무료 글꼴(나눔·Noto·D2Coding·osifont)을 씁니다 |
| **해치 패턴** | 가지고 있는 CAD 프로그램의 `*.pat`, 회사 표준 `*.pat` | `Patterns\` | 패턴 창 '사용자' 탭에 나옵니다. **내장 패턴과 이름이 같으면(예: ANSI31) 넣은 파일의 정의로 그립니다.** | 직접 만든 내장 패턴 47종(ANSI31~38, ISO02~15, 벽돌·육각형·흙·콘크리트 등)을 씁니다 |
| **선종류** | 가지고 있는 CAD 프로그램의 `*.lin`, 회사 표준 `*.lin` | `Linetypes\` | 선종류 관리자 '불러오기' 목록에 나옵니다. **내장 선종류와 이름이 같으면(예: CENTER) 넣은 파일의 정의를 씁니다.** 문자·모양이 들어간 복합 선종류도 됩니다 | 직접 만든 내장 선종류(CENTER·HIDDEN·PHANTOM·DASHED 등과 0.5배·2배, ISO 128 선 ISO02~15와 굵기별, 울타리·철도·배관 선)를 씁니다 |
| **새 도면 템플릿** | 회사 도곽·도면층·문자/치수 스타일이 들어 있는 도면 (2000·2004·2007 등 버전 무관) | `Templates\` | '새로 만들기' 때 템플릿을 고르는 창이 나옵니다 | 내장 A3 템플릿(치수 스타일 ISO-25 KR, 문자 스타일 Malgun)으로 바로 시작합니다 |
| **블록** | 자주 쓰는 부품·기호 도면 (`볼트.dwg` 등) | `Blocks\` | 삽입 > 블록 라이브러리에서 골라 넣습니다. 파일 이름이 블록 이름, 도면의 (0,0)이 삽입 기준점 | — |

### SHX 글꼴은 어디서 구하나요?
- 이미 쓰고 있는 CAD 프로그램의 글꼴 폴더에 있습니다(설치 폴더의 `Fonts` 등). **그 프로그램의 사용권 안에서만** 복사해 쓰세요.
- 인터넷에 공개된 무료 SHX 글꼴도 있습니다. 배포 조건을 확인하고 쓰세요.
- 도면이 쓰는 SHX가 없을 때 무엇으로 대신 그릴지는 `Fonts\fontmap.txt`에 `whgtxt.shx=NanumGothic.ttf`처럼 적어 정할 수 있습니다.

### 해치 패턴·선종류 파일은 어디서 구하나요?
- 쓰고 있는 CAD 프로그램의 설치 폴더(지원 파일 폴더)에 해치 패턴 파일(`*.pat`)과 선종류 파일(`*.lin`)이 있습니다. 역시 **그 프로그램의 사용권 안에서** 쓰세요.
- 회사 표준 파일이 있으면 그것을 넣으면 됩니다. 파일 이름과 개수는 제한이 없습니다.

## 이미 있는 도면은 그대로 보입니다

해치 패턴과 선종류는 **도면 파일 안에 정의가 함께 저장**되어 있습니다. 그래서 다른 CAD에서 만든 도면을 열면, 위 파일을 넣지 않아도 해치와 선 모양은 원래대로 보입니다.
위 폴더는 **새로 해치를 칠하거나 선종류를 새로 불러올 때 고를 목록**을 늘리는 용도입니다. 문자만은 글꼴 파일이 있어야 원래 모양이 나오므로, SHX 글꼴은 넣어 두는 것이 좋습니다.

## 프로그램을 새 버전으로 바꿀 때

위 폴더에 넣은 파일은 그대로 두고 `Free2DCad.exe`만 새 파일로 바꾸면 됩니다.
직접 빌드할 때도 `build\publish.ps1`이 이 폴더들의 파일을 보관했다가 되돌려 놓습니다.
