# Free 2D CAD 사용 설명서

Windows용 무료 2D CAD입니다(DWG·DXF를 직접 읽고 씀). 널리 쓰이는 CAD 한국어판과 같은 명령어·단축키를 씁니다.

## 설치
`Free2DCad.exe` 한 파일만 복사해 실행하면 됩니다. 별도 설치나 라이선스가 필요 없습니다.

## 도면 파일
- DWG와 DXF를 열 수 있습니다. R2000 형식부터 2018 이후 형식까지 지원합니다.
- 저장(Ctrl+S)하면 **DWG 2004 형식**으로 저장됩니다. 국내 협력사 대부분이 쓰는 호환 버전입니다.
- **다른 이름으로 저장**(Ctrl+Shift+S, SAVEAS)에서 형식을 고를 수 있습니다: DWG 2004(기본)·2018·2013·2010·2000, DXF 2018·2013·2010·2007·2004·2000(ASCII), 도면 템플릿(DWT). 고른 형식은 이후 저장(Ctrl+S)에도 쓰입니다. 모두 기존 CAD에서 AUDIT 오류 0건으로 확인했습니다.
- 명령줄에서 OPEN(열기), NEW(새로 만들기), SAVE/QSAVE(저장), SAVEAS(다른 이름으로 저장)를 쓸 수 있습니다.
- 기존 파일에 저장하면 원래 파일은 `.bak`으로 자동 백업됩니다.
- 새 도면은 기본 문자·치수 스타일(ISO-25 KR, 맑은 고딕)과 도면층이 들어 있는 A3 템플릿에서 시작합니다(도면 한계 0,0 ~ 420,297, 배치 용지 ISO A3 — 기존 CAD 새 도면과 같음). 빈 도면은 A3 용지가 화면에 꽉 차게 열리고, 빈 도면에서 전체 보기(Home)도 A3 범위를 보여 줍니다.
- 프로그램을 켜면 Free 2D CAD 시작 로고가 잠시 나오고, 파일을 지정하지 않고 실행하면 시작 페이지가 먼저 보입니다(빈 새 도면 탭은 뒤에 열려 있음). 도면 파일을 더블클릭해 실행하면 그 도면이 바로 열립니다.
- 주석 축척 자동 제안: 주석 축척 1:1인데 그린 도면이 용지(A3)보다 2배 넘게 크면, 문자·치수·지시선 명령을 시작할 때 한 번 "주석 축척을 1:10(으)로 바꿀까요?"처럼 묻습니다(도면마다 한 번, "다시 묻지 않음"으로 끌 수 있음). 적용하면 새 문자·치수·지시선이 그 배율로 만들어집니다(상태 표시줄의 1:10 등에서 언제든 바꿈).
- 선택 상자: 십자 커서 가운데 상자를 고를 수 있는 객체 위에 올리면 상자가 두 배로 커집니다(커진 상자 안에 있는 동안 그 객체가 집힘).
- 크기 가늠: 화면 오른쪽 아래 축척 막대(0 ── 50 mm 등, 확대·축소에 따라 1·2·5 단위로 바뀜)와 "화면 폭 약 ○○ mm"가 늘 보입니다. 선·이동 등 앞 점이 있는 명령에서는 커서 옆에 길이와 각도(예: 258.06 < 20.5°)가 나옵니다.

## 화면 구성
- 위: 빠른 실행 도구, 리본(홈 / 주석 / 보기 / 도구)
- 왼쪽: 도면층 특성 (켜기/끄기, 현재 도면층, 새 도면층)
- 오른쪽: 특성 (선택한 객체의 도면층·색·길이·내용 변경)
- 아래: 모형/배치 탭, 명령줄, 상태 표시줄(그리드, 스냅, 직교, 객체 스냅)

## 도구: 표 추출 (TABLEOUT)
하네스 핀맵·BOM처럼 선과 문자로 그린 표를 두 모서리로 지정하면 행과 열을 인식합니다.
결과는 CSV(엑셀) 파일로 저장하거나 클립보드로 복사할 수 있습니다.

## 알려진 제한
- 블록 안의 문자는 더블클릭해도 바로 편집되지 않습니다(블록 편집 기능은 개선 예정).
- 새로 만든 치수의 화살촉 모양이 기존 도면의 치수 스타일과 다르게 보일 수 있습니다(개선 예정).
- 뷰포트의 비틀기 각도(회전된 뷰포트)는 아직 반영하지 않습니다.
- 꺾기 반지름 치수(DIMJOGGED)는 반지름 치수로 저장되고 꺾인 모양은 치수 블록에 들어 있습니다(기존 CAD에서 치수를 다시 계산하면 꺾임이 일반 반지름 치수로 바뀔 수 있음).
- 연관 배열은 그룹(설명에 배열 설정)으로 저장됩니다. Free 2D CAD의 ARRAYEDIT로 고칠 수 있고, 기존 CAD에서는 그룹으로 보입니다.
- 지시선(MLEADER)은 다중 지시선 객체가 아닌 지시선 + 여러 줄 문자로 저장됩니다(기존 CAD에서 "지시선"으로 보임).

## 플롯(인쇄) — Ctrl+P 또는 PLOT
- 프린터: "PDF로 저장 (Free 2D CAD)" 또는 Windows에 설치된 프린터
- 용지: A4~A0, B4, Letter / 방향: 가로·세로
- 플롯 대상: 화면표시, 범위, 윈도우(도면에서 두 점 지정), 배치
- 축척: 용지에 맞춤, 또는 `1 mm = N 단위` 직접 입력 / 플롯의 중심 맞춤
- 플롯 스타일: acad.ctb(컬러, 흰색 선은 검정으로) / monochrome.ctb(흑백)
- PDF는 선과 글자가 모두 벡터라 확대해도 깨지지 않고, 글꼴이 없는 PC에서도 똑같이 보입니다.

## 명령 자동완성
명령줄에 글자를 입력하면 그 글자로 시작하는 명령과 별칭이 `L (_LINE)` 형식으로 나열됩니다.
- ↑/↓로 고르고 Enter 또는 Space로 실행, Tab으로 입력칸 채우기, Esc로 닫기
- 입력과 정확히 같은 명령이 미리 선택되어 있으므로 `L` + Enter는 바로 선(LINE)

## 배치(시트)
- 도면 영역 아래 `Model | 배치1 | … | +` 탭에서 공간을 전환합니다.
- `+`를 누르거나 탭을 오른쪽 클릭 → 새 배치: A3 가로 용지와 모형 전체가 보이는 뷰포트가 만들어집니다.
- 탭을 오른쪽 클릭하면 이름 바꾸기, 삭제, 이동을 할 수 있습니다. 탭을 더블클릭해도 이름을 바꿀 수 있습니다.
- 배치 탭에서 그린 도형은 도면 공간(표제란 등)에 들어갑니다.
- 명령어: `LAYOUT`(LO) 뒤에 N(새로 만들기), R(이름 바꾸기), D(삭제), S(현재로 설정)

## 해치(빗금) — H 또는 HATCH, 리본 그리기 > 해치
**해치 및 그라데이션** 창이 열립니다.
1. **패턴 고르기**: 패턴 목록 또는 `...` 버튼(ANSI / ISO / 기타 탭의 견본 그림). 각도와 축척을 정합니다. 유형을 '사용자 정의'로 바꾸면 간격과 이중(교차선)을 지정할 수 있습니다.
2. **경계 지정**
   - **추가: 내부 점 선택** — 창이 잠시 닫히면 닫힌 영역 안쪽을 클릭합니다. 선 여러 개가 만나서 이루는 영역도 찾습니다. 여러 곳을 클릭한 뒤 Enter를 누르면 창으로 돌아옵니다.
   - **추가: 객체 선택** — 원, 닫힌 폴리선, 타원 같은 닫힌 객체를 클릭합니다.
   - 경계는 **현재 화면에 보이는 객체**에서 찾습니다. 경계를 못 찾으면 영역 전체가 보이도록 확대/축소한 뒤 다시 하십시오.
3. **고립영역(안쪽 도형) 처리** — 창 오른쪽(`<`/`>` 버튼으로 펼침)
   - 외부(기본): 가장 바깥 영역만 칠하고 안쪽 도형은 비웁니다.
   - 보통: 바깥에서부터 한 겹씩 번갈아 칠합니다.
   - 무시: 안쪽 도형과 상관없이 전체를 칠합니다.
4. **미리보기**로 확인하고(Enter 또는 클릭으로 돌아옴) **확인**을 누르면 만들어집니다. Ctrl+Z 한 번이면 취소됩니다.
- **그라데이션** 탭: 두 색 또는 한 색의 9가지 그라데이션 채우기.
- **내장 패턴**: 이 프로그램이 직접 정의한 47종 — ANSI 탭(ANSI31~38, 단면 재료 기호), ISO 탭(ISO02~15, ISO 128 선 모양), 기타 탭(SOLID·격자·벽돌·블록·타일·육각형·지그재그·흙·풀·모래·자갈·콘크리트 등). 크기는 mm 기준입니다.
- **패턴 추가**: 쓰려는 패턴 파일(*.pat, 예: 가지고 있는 다른 CAD 프로그램의 패턴 파일·회사 표준 패턴)을 Free 2D CAD 실행 파일이 있는 폴더의 `Patterns` 폴더에 넣고 Free 2D CAD를 다시 실행하면 패턴 창의 '사용자' 탭에 나옵니다. 내장 패턴과 이름이 같으면 넣은 파일의 정의로 그립니다(자세한 것은 [자료_추가하기.md](자료_추가하기.md)). 해치가 있는 도면을 열면 그 도면에 쓰인 패턴도 '사용자' 탭에 추가됩니다.
- **속성 상속**: 이미 있는 해치를 클릭해 패턴·각도·축척·색·도면층을 그대로 가져옵니다.
- 명령줄에서만 쓰려면: HATCH 실행 중 `S`(객체 선택), `K`(내부 점 선택), `U`(마지막 경계 취소), `T`(설정 창).
- 연관 해치는 다른 CAD에서 열어도 경계와 연결된 해치로 열립니다. 다만 Free 2D CAD 안에서 경계를 움직여도 해치가 따라 바뀌지는 않습니다(개선 예정).

## 그립 편집 (객체를 클릭해서 바로 수정)
- 객체를 클릭하면 점선 테두리와 **파란 네모(그립)** 가 나옵니다. 그립을 클릭하면 빨갛게 바뀌고, 원하는 위치를 한 번 더 클릭하면 반영됩니다(누른 채 끌어서 놓아도 됩니다). Esc를 누르면 취소됩니다.
  - 선: 양 끝(늘이기), 가운데(이동) · 원: 중심(이동), 상하좌우(반지름) · 호: 중심(이동), 시작·중간·끝(모양)
  - 폴리선: 꼭짓점, 직선 구간 가운데(그 구간 이동) · 타원: 중심, 축 끝(축 길이) · 스플라인: 맞춤점/제어점
  - 치수: 두 측정점, 치수선 위치, 문자 위치 · 문자·블록·점: 삽입점(이동)
- 객체 스냅·그리드 스냅·직교·극좌표 추적이 그립 편집에도 적용됩니다. Ctrl+Z 한 번으로 되돌립니다.

## 치수·문자 더블클릭 편집 (작업 화면에서 바로)
- 문자를 더블클릭하면 문자가 원래 자리·모양 그대로 있는 상태에서 바로 고칠 수 있습니다. 입력한 글자가 도면 문자에 곧바로 반영되고, 커서와 선택 영역이 문자 위에 표시됩니다.
- 문자 안을 클릭하면 그 자리로 커서가 옮겨지고, Shift+방향키로 글자를 선택할 수 있습니다. **Enter** = 확정, **Esc** = 취소, 문자 밖을 클릭해도 확정됩니다.
- 여러 줄 문자는 Enter가 줄 바꿈이고 **Ctrl+Enter**가 확정입니다.
- 서식 코드는 보이지 않고, 고친 부분만 바뀌므로 글꼴·들여쓰기·탭·밑줄 같은 서식은 그대로 유지됩니다.
- 치수를 더블클릭하면 치수 문자도 그 자리에서 바로 고칩니다(화면에 보이는 값, 예: ∅4.5). 측정값 부분을 그대로 두고 앞뒤만 고치면(예: ∅4.5 TYP) 치수를 늘이거나 줄일 때 값이 계속 따라 바뀝니다. 측정값을 지우고 다른 글자를 쓰면 고정 문자가 됩니다.
- 고친 내용은 Ctrl+Z로 되돌릴 수 있습니다.

## 여러 줄 문자(MTEXT) 표시
- 문단 들여쓰기·탭 위치, 폭 비율(\W), 글자 높이(\H), 글꼴(\f), 색(\C), 밑줄(\L), 분수(\S), 줄 간격(정확히/최소)을 반영해 배치합니다.
- 문자는 글자 모양(SHX 획 또는 TrueType 윤곽)으로 그려서, 선택하거나 커서를 올리면 글자 하나하나의 모양이 강조됩니다.

## 특성 창(Ctrl+1)에서 문자 바꾸기
- 문자를 고르면 특성 창의 **스타일**을 목록에서 바로 바꿀 수 있습니다. 회전 각도도 입력해서 바꿉니다.
- 여러 줄 문자는 **자리맞추기**(맨 위 왼쪽 등 9가지)와 **정의 폭**도 바꿀 수 있습니다.
- TrueType 문자 스타일은 스타일에 저장된 글꼴 이름(예: Standard → 굴림체)으로 표시합니다.

## 마우스 올림 강조
- 명령이 없을 때 객체 위에 커서를 올리면 선택한 것처럼 파란 점선으로 강조됩니다. 커서를 빼면 원래대로 돌아갑니다.

## 도면 열기 정보 (명령줄)
- 도면을 열면 명령줄에 파일 경로, 글꼴 대체(`[romans.shx] 글꼴을 [xxx.shx] 글꼴 대신 사용.`), 파일 버전(예: R18 (2004)), 객체·도면층·블록·배치 수가 표시됩니다.

## 도움선 (극좌표 추적 F10, 객체 스냅 추적 F11)
- **극좌표(F10)**: 명령·그립 편집 중 기준점에서 0°, 45°, 90°… 방향 근처로 가면 초록 점선과 "극좌표: 거리 < 각도"가 나오고 그 선 위에 정확히 찍힙니다. 직교(F8)와 동시에 켤 수 없습니다.
- **객체 추적(F11)**: 끝점·중심 같은 스냅점 위에 잠깐 머물면 작은 초록 +로 표시되고, 그 점과 가로·세로로 맞는 자리에서 점선이 나옵니다. 두 점선이 만나는 곳에도 맞춰집니다.

## 화면 재생성·설정 초기화
- **REGEN(RE) / REGENALL(REA)**: 화면을 도면 데이터로 다시 그립니다(확대 상태 유지).
- **설정 초기화**: 제목 줄의 주황색 되돌림 아이콘(또는 RESETSETTINGS). 무엇을 바꿨는지 기억나지 않을 때 스냅·그리드·직교·극좌표·객체 스냅 모드·팔레트·명령줄·해치 기본값을 처음 상태로 되돌립니다. 도면 내용은 바뀌지 않습니다.

## 상태 표시줄 옵션 (버튼 오른쪽 클릭)
- **객체 스냅(F3)**: 끝점·중간점·중심·사분점·교차점·삽입점·노드·근처점을 하나씩 켜고 끔, 모두 선택/모두 지우기, 설정...
- **극좌표(F10)**: 증분 각도 90° / 45° / 30° / 22.5° / 18° / 15° / 10° / 5° 선택
- **스냅(F9)·그리드(F7)·객체 추적(F11)**: 켜기, 설정...(간격 등) · **직교(F8)·선가중치**: 켜기
- 바꾼 설정은 자동 저장되어 다음 실행 때도 유지됩니다. 처음 상태로 돌리려면 제목 줄의 설정 초기화 아이콘.

## 사용자 글꼴 (실행 파일 옆 Fonts 폴더)
- `Fonts` 폴더에 글꼴 파일(ttf/otf/ttc)을 넣으면 Windows에 설치하지 않아도 도면 문자에 쓰이고, 문자 스타일 글꼴 목록 맨 위에 ★로 나옵니다.
- 샘플 무료 글꼴(나눔고딕, 나눔고딕 Bold, 나눔명조, 나눔바른고딕, D2Coding — SIL OFL, 무료·재배포 가능)이 들어 있습니다.
- `Fonts\fontmap.txt`에 `whgtxt.shx=NanumGothic.ttf`처럼 적으면 그 SHX 글꼴을 TTF로 표시합니다(기본은 SHX 그대로).
- 문자 스타일에는 글꼴 파일 이름이 저장됩니다. 다른 PC에서 같은 모양으로 보려면 그 PC에도 같은 글꼴이 있어야 합니다.

## 사용자 폴더 (실행 파일 옆, 도구 > 사용자 폴더 열기)
배포본에 넣지 않은 SHX 글꼴·패턴·선종류 파일을 어디에 넣으면 되는지는 [자료_추가하기.md](자료_추가하기.md)에 정리되어 있습니다.

| 폴더 | 넣는 것 | 쓰이는 곳 |
| :--- | :--- | :--- |
| Fonts | 글꼴(ttf/otf/ttc, shx — 하위 폴더도 찾음), fontmap.txt | 도면 문자, 문자 스타일 목록 |
| Patterns | 해치 패턴(.pat). 기본 패턴 47종은 프로그램에 내장, 같은 이름이면 넣은 파일 우선 | 해치 패턴 창 ANSI/ISO/기타 탭, 그 밖의 파일은 '사용자' 탭 |
| Templates | 템플릿 도면(.dwg·.dwt·.dxf, 2000·2004·2007 등 버전 무관) | 새로 만들기 때 템플릿 선택 (같은 이름이면 확장자로 구별) |
| Linetypes | 선종류(.lin 형식, 복합 선종류 포함). 같은 이름이면 넣은 파일 우선 | 선종류 관리자 '불러오기' |
| Blocks | 블록으로 쓸 도면(.dwg) | 삽입 > 블록 라이브러리 (BLOCKLIB) — 파일 이름이 블록 이름, 원점이 기준점 |
- 넣은 뒤 Free 2D CAD를 다시 실행하면 적용됩니다(템플릿은 새로 만들기를 누를 때마다 다시 찾음). Free 2D CAD 폴더째 복사하면 모두 같이 옮겨집니다. 새 버전 배포본을 만들어도 이 폴더들에 넣어 둔 파일은 지워지지 않습니다.

## 최근 파일 · 옵션
- 파일 > **최근 파일**: 최근 연 도면 10개 (다음 실행에도 유지, 시작 페이지에도 표시).
- 도구 > **옵션**(OPTIONS, OP): 도면 단위·스냅·그리드·객체 스냅, **표시** 탭의 대체 글꼴. 도구 > **설정 초기화**: 처음 상태로.

## SHX 선 글꼴 (기본 글꼴)
- 도면 문자는 SHX 선 글꼴로 그립니다. 배포본에는 SHX 글꼴이 없으므로, 가지고 있는 SHX 파일(romans.shx, whgtxt.shx 등)을 `Fonts\SHX` 폴더에 넣으면 원본과 같은 글자 폭·배치로 나옵니다.
- 도면이 쓰는 SHX 파일이 없으면 ① `Fonts\fontmap.txt` 대응 ② 옵션(OPTIONS) > 표시 탭의 **대체 글꼴**(기본 romans.shx, 한글 큰 글꼴 whgtxt.shx) 순으로 대신 그립니다. 어떤 글꼴을 대신 썼는지는 도면을 열 때 명령줄에 나옵니다.
- TrueType으로 보고 싶으면 대체 글꼴을 .ttf로 고르거나 fontmap.txt에 적습니다(글자 길이가 원본과 달라질 수 있음).
- 문자 스타일 창(STYLE)에서 SHX 글꼴과 **큰 글꼴**(한글용 SHX)을 고를 수 있고, 미리보기도 선 글꼴로 보입니다.
- SHX 파일은 각 제작사의 저작물이라 이 배포본에는 들어 있지 않습니다. 가지고 있는 SHX의 라이선스를 확인하고 쓰세요.

## 리본 (홈 탭) — 기존 CAD와 같은 구성
- 패널: 그리기 · 수정 · 도면층 · 주석 · 블록 · 속성 · 그룹 · 유틸리티 · 클립보드.
- **패널 제목 ▾**(예: "그리기 ▾")를 누르면 아래로 추가 도구가 펼쳐집니다. 그리기: 스플라인·타원·점·도넛·구름형·솔리드·등분할/길이 분할, 수정: 도면층별로 설정·길이 조정·폴리선 편집·정렬·끊기·점에서 끊기·결합·반전·그리기 순서, 도면층: 이전 도면층 상태, 주석: 문자/치수 스타일, 블록: 속성 정의·동기화·표시·기준점, 그룹: 그룹 선택 켜기/끄기, 유틸리티: ID·점 스타일.
- **분할 버튼**: 아이콘(위쪽)을 누르면 마지막에 고른 방식으로 바로 실행, 글자▾(아래쪽, 작은 버튼은 오른쪽 ▾)를 누르면 방식 목록이 나옵니다.
  - 원: 중심-반지름 / 중심-지름 / 2점 / 3점 / 접선-접선-반지름 / 접선-접선-접선
  - 호: 3점, 시작-중심-끝/각도/길이, 시작-끝-각도/방향/반지름/중심, 중심-시작-끝/각도/길이
  - 직사각형·폴리곤(중심-꼭짓점/중심-변/모서리), 타원형 호, 해치·그라데이션·경계
  - 배열(직사각형/원형/경로), 자르기/연장, 모깎기/모따기, 그리기 순서(맨 앞/맨 뒤/객체 위/아래, 해치 뒤로, 문자·치수·지시선 앞으로)
  - 주석 **선형**(큰 아이콘): 선형 / 정렬 / 각도 / 호 길이 / 세로좌표 / 기준선 / 연속, **중심선**: 중심 표시 / 지름 / 반지름, **지시선**: 지시선 / 빠른 지시선
- 상단 메뉴(그리기·치수·수정·형식·도구)에도 같은 명령이 들어 있습니다 (호·원·배열·도면층 도구·그리기 순서·그룹은 하위 메뉴).

## 새 그리기·수정 명령 요약
- 원 CIRCLE: `3P`, `2P`, `T`(접선 접선 반지름). 리본에서 접선 접선 접선도 고를 수 있습니다.
- 호 ARC: 시작점 다음 `C`(중심) / `E`(끝점), 그다음 `A`(각도) / `L`(현 길이) / `D`(방향) / `R`(반지름).
- 폴리선 PLINE: `A` 호 / `L` 선 / `W` 폭 / `H` 반폭 / `U` 명령 취소 / `C` 닫기. 호는 앞 조각에 접하게 이어집니다.
- 폴리곤 POLYGON: 면의 수 → 중심 → `I`(내접)/`C`(외접) → 반지름, 또는 `E`(모서리 두 점).
- 타원 ELLIPSE: 축 끝점 두 개 + 다른 축 거리(`R` 회전), `C` 중심 방식, `A` 타원형 호(시작·끝 각도).
- 스플라인 SPLINE: 맞춤점(점을 지나는 곡선) / `M`으로 조정점 방식, `C` 닫기, Enter 끝.
- 점 POINT·등분할 DIVIDE·길이 분할 MEASURE: 점 모양·크기는 점 스타일(PTYPE) 창에서 바꿉니다.
- 구성선 XLINE(`H` 수평 / `V` 수직 / `A` 각도 / `B` 이등분)·광선 RAY: 화면 끝까지 그려지며 전체 보기 범위에는 넣지 않습니다.
- 도넛 DONUT, 구름형 수정 기호 REVCLOUD(직사각형·다각형·`O` 객체, `A` 호 길이), 2D 솔리드 SOLID, 경계 BOUNDARY(안쪽 점 → 닫힌 폴리선).
- 길이 조정 LENGTHEN: `DE` 증분 / `P` 퍼센트 / `T` 합계 / `DY` 동적 — 고른 점에 가까운 끝이 바뀝니다.
- 점에서 끊기 BREAKATPOINT, 반전 REVERSE, 정렬 ALIGN(점 1~2쌍, 축척 여부), 폴리선 편집 PEDIT(닫기·열기·결합·폭·곡선 해제·스플라인·반전·명령 취소; 선·호를 고르면 폴리선으로 바꿀지 묻습니다).
- 그리기 순서 DRAWORDER: 맨 앞(F)/맨 뒤(B)/객체 위(A)/아래(U). 저장해도 순서가 유지됩니다.
- 복제 ADDSELECTED: 고른 객체와 같은 종류를 그리는 명령이 시작되고, 새 객체에 원본의 도면층·색·선종류가 입혀집니다.

## 치수·지시선
- 선형/정렬 치수: 첫 점에서 Enter → 객체(선·호·원·폴리선 조각) 선택. 치수선 위치에서 `T`/`M` 문자(`<>` = 측정값), `A` 문자 각도, `H` 수평, `V` 수직, `R` 회전.
- 기준선 DIMBASELINE / 연속 DIMCONTINUE: 마지막 치수(또는 `S`로 고른 치수)에 이어서 그립니다. `U` 명령 취소.
- 세로좌표 DIMORDINATE(위아래로 끌면 X, 좌우로 끌면 Y), 호 길이 DIMARC(⌒ 기호), 중심 표시 DIMCENTER(치수 스타일 중심 표시 크기, 음수면 중심선까지).
- 공차·대체 단위: 치수 스타일 수정 창의 Tolerances(없음/대칭/편차/한계/기본)·Alternate Units 탭이나 속성창 "허용 오차"·"대체 단위"에서 켭니다. 편차는 +상한/-하한을 위아래로 쌓고, 대칭은 30.0±0.1, 한계는 30.1/29.8, 기본은 문자 둘레에 상자, 대체 단위는 30.0 [762.00mm]처럼 기존 CAD와 같게 그립니다. 지름 기호는 ∅입니다.
- 지시선 MLEADER/QLEADER: 화살촉 점 → 연결선 점 → 문자. 문자를 명령줄에 입력하지 않고 Enter를 누르면 그 자리에서 바로 입력합니다.
- 지시선 LEADER (기존 CAD와 같음): "지시선의 시작:" → "다음 점:" → "지점까지: [형식(F)/취소(U)]/<주석>:"에서 점을 계속 찍습니다.
  - 형식(F): 화살촉(A)/없음(N)/스플라인(S)/직선(ST). 취소(U): 마지막 점을 뺍니다.
  - Enter(주석) → "주석 문자의 첫 줄/<옵션>:"에 글을 치면(띄어쓰기 가능) 다음 줄을 계속 받고, 빈 Enter로 끝납니다.
  - 첫 줄에서 바로 Enter → "치수 문자 옵션: [블록(B)/복사(C)/없음(N)/공차(T)]/<Mtext>:" — Enter = 화면에서 바로 입력, C = 고른 문자·공차·블록을 끝점에 복사, N = 지시선만, T = 기하학적 공차 창 → 끝점에 공차, B = 블록 이름(?, 찾아보기) → 삽입점·축척·회전.

## 도면층 도구 (리본 도면층 패널)
- 객체를 골라 그 도면층에 적용: 현재로(LAYMCUR), 끄기(LAYOFF), 동결(LAYFRZ), 잠금/해제(LAYLCK/LAYULK), 격리(LAYISO → LAYUNISO로 되돌림), 현재 도면층으로 변경(LAYCUR), 일치(LAYMCH, `N`으로 이름 입력), 삭제(LAYDEL: 도면층과 그 객체 모두, 확인 후).
- 모든 도면층 켜기(LAYON), 모든 동결 해제(LAYTHW), 이전 도면층 상태(LAYERP). 모두 명령 취소(Ctrl+Z)가 됩니다.

## 블록 속성·그룹
- 속성 정의 ATTDEF(태그 → 프롬프트 → 기본값 → 높이 → 시작점, `I` 숨김, `C` 상수) → BLOCK에 함께 넣으면 INSERT할 때 값을 묻습니다(Enter = 기본값).
- 속성 동기화 ATTSYNC(정의를 바꾼 뒤 참조 갱신, 값 유지), 속성 표시 ATTDISP(일반/켜기/끄기), 기준점 BASE.
- 그룹 GROUP(이름)·QGROUP(무명)·UNGROUP. 그룹 선택이 켜져 있으면 구성원 하나를 고를 때 그룹 전체가 선택됩니다 (그룹 패널 ▾ → 그룹 선택 켜기/끄기).
- 빠른 선택 QSELECT: 객체 유형·특성(도면층·색상·선종류·문자 내용)·연산자(=, <>, 와일드카드)로 고릅니다.

## 리본 탭 (기존 CAD와 같은 패널)
- 편집: 수정(특성 일치·이동·복사·복제·회전·대칭·배열·끊기·연장·길이 분할·모깎기·폴리선/스플라인 편집·정렬·분해) · 선택(빠른 선택·모두 선택·유사 선택·그룹 선택) · 그리기 순서 · 클립보드
- 그리기: 선·폴리선·구성선(수평/수직/각도/이등분)·다중선·스플라인·점·원·호·타원·타원형 호·직사각형/폴리곤·해치·도넛·솔리드·와이프아웃·구름형·블록 삽입·테이블 · 객체 스냅 설정 · 설정(단위·점 스타일·선종류·기준점·제도 설정·문자 스타일)
- 삽입: 블록 삽입·속성 편집·블록 라이브러리 · 블록 정의(블록 작성/파일로 저장·속성 정의·속성 표시·속성 추출·동기화·블록 편집기) · 참조(외부 참조 부착·외부 참조 관리자) · 배치
- 주석: 문자 · 치수(선형▾·지름▾·치수 스타일·치수 문자 편집▾·기준선/연속·호 길이·세로좌표·기울기·간격·꺾기) · 중심선 · 지시선 · 테이블 · 마크업(와이프아웃·구름형)
- 보기: 재생성·줌▾(범위/확대/축소/윈도우/이전/전체/중심/객체)·초점 이동 · 배치 · 창(속성·도면층·명령줄·문자 윈도우)
- 출력: 저장·다른 이름으로·블록 저장·PDF/PNG/CSV/DXF 출력·인쇄
- 도구: 조회(거리·면적·총 길이·ID·객체 정보·도면 상태·표 추출) · 관리(옵션·제도 설정·설정 초기화) · 탐색기(도면층·도면층 상태·문자/치수 스타일·선종류·블록 라이브러리·그룹)

## 주석 축척 (상태 표시줄 1:1)
- 누르면 축척 목록(1:1~1:500, 2:1~10:1)이 나옵니다. 고른 축척에 맞춰 새 문자·치수·지시선이 그 배율로 만들어집니다(예: 1:50이면 출력 높이 3.5인 문자를 175 높이로). 치수는 "스타일 이름 1-50"처럼 전체 축척만 바꾼 치수 스타일을 자동으로 만들어 씁니다.

## 블록 편집기 (BEDIT)
- 블록을 고르면(블록 참조를 선택한 상태면 그 블록) 화면이 블록 정의로 바뀌고 위쪽에 "블록 편집기" 띠가 보입니다. 그리기·수정 명령으로 고친 뒤 "블록 편집기 닫기"(BCLOSE)를 누르면 저장/버리기를 묻고 도면으로 돌아갑니다. 속성을 바꿨다면 ATTSYNC로 참조를 맞추십시오.

## 배열 (기존 CAD와 같은 흐름)
- 객체 선택 → (원형: 중심점 / 경로: 경로 곡선) → 기본값으로 미리보기 → 옵션 [연관(AS)/기준점(B)/수량(COU)/간격(S)/열(C)/행(R)/…/종료(X)] → Enter로 작성. 연관 배열은 ARRAYEDIT로 개수·간격·각도를 다시 바꿀 수 있습니다.

## 각도 치수
- 선 두 개, 호, 원, 또는 Enter 후 세 점. 호를 놓는 쪽의 각을 잽니다. 문자는 치수 스타일대로(수평 문자이고 치수선이 수평에 가까우면 위쪽, 기울어지면 호 가운데에 두고 호를 끊음).

## 여러 도면 탭
- 도면을 열거나 새로 만들면 탭이 하나씩 늘어납니다(기존 CAD처럼). 탭을 누르면 그 도면으로 바뀌고, 도면마다 화면 위치·배치·선택을 기억합니다.
- 탭의 ✕(또는 마우스 가운데 버튼)로 닫으면 바뀐 내용이 있을 때 저장 여부를 묻습니다. 이미 열린 파일을 다시 열면 그 탭으로 갑니다. 손대지 않은 빈 새 도면은 파일을 열 때 그 파일로 대신합니다.
- 창을 닫으면 바뀐 도면마다 저장 여부를 묻습니다.

## 텍스트 편집 탭 (문자를 고치는 동안)
- 여러 줄 문자·다중지시선·단일 행 문자를 고치는 동안 리본에 분홍색 "텍스트 편집" 탭이 나타납니다.
- 스타일: 문자 스타일, 높이(글자를 골랐으면 그 글자만). 서식: 굵게·기울임·취소선 / 밑줄·윗줄·위 첨자 / 대문자·소문자·아래 첨자, 글꼴, 색, 기울기·자간·폭, 서식 지우기, 단락 결합.
- 글자를 고르고 누르면 그 글자에만 적용되고, 고르지 않고 누르면 다음에 치는 글자에 적용됩니다. 커서가 있는 글자의 서식에 따라 B·I·U 버튼이 눌린 상태로 보입니다.
- 단락: 자리맞춤(9가지), 목록(문자·숫자·글머리), 줄 간격, 정렬(왼쪽·가운데·오른쪽·양쪽·균등). 삽입: 취소·명령 복구, 기호(° ± Ø 등), 필드(날짜·파일 이름·작성자). 도구: 찾기 및 바꾸기, 텍스트 가져오기(.txt), 자동 대문자. 옵션: 자(편집 상자 위 눈금), 스택 텍스트(1/2 → 분수). 완료로 닫습니다.
- 단락 창(단락 ▸ 단락): 탭(왼쪽·가운데·오른쪽·소수점, 추가·수정·제거), 왼쪽 들여쓰기(첫 번째·행간), 오른쪽 들여쓰기, 단락 정렬, 단락 간격(이전·이후), 단락 줄 간격(정확히·최소·배수). 기존 CAD와 같은 형식(문자 높이 배수의 \px 코드)으로 저장합니다.
- 열(삽입 ▸ 열): 열 없음 / 동적 열(자동·수동 높이) / 정적 열(2~6, 더 보기) / 열 설정(칼럼 유형·칼럼 번호·높이·칼럼 너비·갭·총계). 글은 열 너비로 줄을 나누고 열 높이를 넘으면 다음 열로 넘어갑니다. 기존 CAD가 R2004로 나눠 저장한 열 문자도 열 때 하나로 합쳐집니다.
- 배경 마스크(서식 ▸ 배경 마스크): 배경 마스크 사용, 테두리 간격띄우기 계수(1~5), 채우기 색(빨간색~검정색·색상 선택) 또는 그리기 배경색. 글상자 뒤를 그 색으로 칠해 아래 객체를 가립니다.
- 맞춤법 검사(옵션 ▸ 맞춤법 검사, 기본 켜짐): 틀린 영어 단어 아래 빨간 물결선. 그 단어를 마우스 오른쪽 클릭하면 추천 단어(추가 제안·모두 무시)가 나옵니다. 사전은 기존 CAD와 같은 Hunspell en_US이며 앱에 들어 있어 인터넷·설치가 필요 없습니다. 한글·숫자가 붙은 기호(M10, 3EA 등)는 검사하지 않습니다.
- 문자 편집 중 마우스 오른쪽 클릭: 기존 CAD와 같은 편집 메뉴(추천 단어, 모두 선택·잘라내기·복사·붙여넣기, 필드 삽입·기호·텍스트 가져오기, 단락 정렬·단락·글머리 기호 및 목록·Columns, 찾기 및 바꾸기·대소문자 변경·자동 대문자, 단락 결합·서식 지우기·배경 마스크·편집기 설정, 도움말).
- 더 보기: 문자 세트(선택 글자 글꼴의 문자 집합), 편집기 설정 ▸ 텍스트 강조 색상(선택 영역 색), 도움말.
- MTEXT는 두 구석을 찍으면 바로 화면에서 입력합니다(아무것도 안 쓰고 끝내면 만들지 않음). 옵션: 정렬(J)·회전각도(R)·텍스트스타일(S)·텍스트높이(H)·너비(W).

## 다중 지시선 (MLEADER)
- 화살촉 위치 → 두 번째 점을 찍으면 바로 화면에서 문자를 입력합니다(텍스트 편집 탭 사용 가능). 지시선연결선먼저(L)로 연결점부터 찍을 수도 있습니다.
- 기존 CAD와 같은 MULTILEADER 객체로 저장되어 기존 CAD에서 그대로 열리고 고칠 수 있습니다. 그립으로 화살촉·연결점을 옮길 수 있습니다.

## 꺾기 반지름 치수 (DIMJOGGED)
- 호 또는 원 → 중심 위치 재정의 → 치수선 위치 → 꺾임 위치. 기존 CAD와 같은 "꺾임 치수" 객체로 저장됩니다.

## 모깎기·모따기 (FILLET·CHAMFER)
- 선·호·원·폴리선을 모깎기합니다. 옵션: 폴리라인(P, 모든 꼭짓점)·반지름(R)·자르기(T)·다중(M). 평행한 두 선은 반원으로 잇고, Shift를 누른 채 고르면 반지름 0(모서리 맞춤).
- 모따기: 폴리라인(P)·거리(D)·각도(A)·방법(E)·자르기(T)·다중(M). 문구와 기본값은 기존 CAD와 같습니다.

## 찾기 및 바꾸기 (FIND, 편집 메뉴)
- 찾을 내용·바꿀 내용·어디에서 찾기(전체 도면/현재 선택). 결과 목록에서 고르면 그 문자로 확대합니다. 바꾸기·모두 바꾸기(한 번에 되돌리기)·찾기(다시 누르면 다음).
- 검색 옵션: 대소문자 구분, 전체 단어만, 와일드카드(* ?), 숨겨진 항목 무시. 텍스트 유형: 블록 속성 값, 치수·지시선 문자, 단일·여러 줄 문자, 표 문자. 서식(밑줄·색 등)은 그대로 둡니다.

## 빠른 치수 (QDIM, 치수 메뉴)
- 도형을 고르고 치수선 위치를 찍으면 끝점마다 치수를 한 번에 만듭니다. 커서가 도형 위·아래면 가로, 왼쪽·오른쪽이면 세로.
- [Continuous(연속)/Staggered(엇갈림)/Baseline(기준선)/Ordinate(세로좌표)/Radius/Diameter/datumPoint(기준점)/Edit(점 빼기·더하기)/seTtings(끝점/교차점)].

## 기하 공차 (TOLERANCE, 치수 메뉴)
- 기존 CAD와 같은 "기하학적 공차" 대화상자: 기호(14가지), 공차 1·2(지름 기호·값·재료 조건 Ⓜ Ⓛ Ⓢ), 데이터 1~3, 두 줄, 높이·투영 공차 영역, 데이터 식별자. 확인 후 공차 위치를 찍습니다.
- 틀 모양·저장 형식이 기존 CAD와 같아 서로 열 수 있습니다.

## 외부 참조 (XREF·XATTACH, 삽입 탭 > 참조)
- 부착: 파일 선택 → 참조 유형(부착/중첩)·경로 유지(전체/상대/없음)·삽입점·축척·회전. 도면에는 경로만 저장되고, 열 때마다 참조 파일을 읽어 그립니다(기존 CAD와 같은 형식).
- Xref 관리자: 참조 이름·상태(로드됨/언로드됨/찾을 수 없음)·참조 수·크기·형식·날짜·경로. 분리·다시 로드·언로드·결합(일반 블록으로 바꿈)·열기(새 탭)·경로 찾아보기.
- 경로를 찾을 때: 저장된 경로 → 이 도면 폴더 기준 상대 경로 → 이 도면 폴더의 같은 이름 파일.

## 저장 형식 (기존 CAD와 같은 자리)
- 도면층 상태는 기존 CAD 형식(도면층 테이블의 ACAD_LAYERSTATES)으로 저장되어 기존 CAD 도면층 상태 관리자에서도 보입니다. 예전 Free 2D CAD 형식도 읽습니다.
- 주석 축척은 CANNOSCALE로 저장되어 다시 열거나 기존 CAD에서 열어도 유지됩니다.
- 문자 기본 높이는 도면마다 기억합니다(TEXTSIZE).

## 커서 옆 안내
- 명령 중에는 커서 옆에 지금 할 일(예: "<치수호의위치(L)>")과, 점을 찍는 단계에서는 X·Y 좌표가 보입니다(기존 CAD 동적 입력처럼). 객체를 고르는 단계에서는 객체 스냅이 잡히지 않고, 이미 고른 객체는 점선으로 보입니다.

## 선종류 (LINETYPE, 형식 > 선종류)
- '불러오기'의 내장 선종류는 이 프로그램이 직접 정의한 것입니다(mm): CENTER·HIDDEN·DASHED·PHANTOM·DASHDOT·DIVIDE·BORDER·DOT·LONGDASH·DASHDASHDOT과 각각의 0.5배(이름2)·2배(이름X2), INVISIBLE, ISO 128 선 ISO02~ISO15(굵기 1)와 굵기별(ISO02_0.25·_0.35·_0.5·_0.7). 가지고 있는 *.lin 파일을 `Linetypes` 폴더에 넣으면 목록에 추가되고, 이름이 같으면 넣은 파일의 정의를 씁니다.
- 문자·모양이 들어간 선도 그립니다: 내장 FENCE_CIRCLE·FENCE_SQUARE·RAILWAY·RAILWAY2·ZIGZAG_LINE·INSULATION_LINE(모양), 배관·설비 선 PIPE_GAS·PIPE_WATER·PIPE_HOT·PIPE_RETURN·PIPE_DRAIN·PIPE_VENT·PIPE_OIL·PIPE_AIR·PIPE_STEAM·PIPE_FIRE·LINE_ELEC·LINE_TEL(문자). 모양 파일 이름은 다른 CAD와 호환되도록 ltypeshp.shx로 저장하고, 모양은 Free 2D CAD가 직접 그리므로 파일이 없어도 보입니다.
- 선 패턴은 기존 CAD처럼 선 가운데를 기준으로 양 끝이 같게 놓입니다. 한 주기보다 짧은 선은 실선, 폴리선은 '선종류 생성(PLINEGEN)'이 꺼져 있으면 구간마다 새로 시작합니다. 선 끝을 넘는 문자·모양은 빼고 그 자리를 실선으로 잇습니다.
- 속성창·리본의 선종류 목록에 이름과 함께 선 모양 견본이 보입니다(이름순).

## 속성창 (기존 CAD와 같은 항목)
- 객체 하나를 고르면 기존 CAD와 같은 분류가 나옵니다: 일반(색상·도면층·선 종류·선 종류 비율·플롯 스타일·선 두께·하이퍼링크·투명도·두께·가시성), 3D 시각화(재질), 기하학, 텍스트, 기타. 여러 종류를 함께 고르면 일반·3D 시각화만 나옵니다(위쪽 목록에서 종류를 고르면 그 종류만).
- 값 칸에 새 값을 넣고 Enter(또는 다른 칸 클릭)로 바꿉니다. 모두 Ctrl+Z로 되돌릴 수 있고, 입력 칸 안에서는 Ctrl+A/C/V/Z가 그 칸에 적용됩니다.
- 선: 시작·끝 X/Y/Z, 델타, 길이, 각도. 원: 중심, 반지름, 지름, 둘레·면적(넣으면 반지름이 바뀜). 호: 시작·끝점, 중심, 반지름, 시작·끝 각도, 전체 각도, 호 길이, 면적. 타원: 주·부 반지름, 반지름 비율, 시작·끝 각도, 축 벡터, 면적.
- 폴리라인: 꼭짓점 번호를 골라 그 꼭짓점 X/Y·시작/끝 세그먼트 폭, 전체 너비, 고도, 면적, 길이, 닫힘, 선종류 생성. 직사각형이면 "Rectangle shape"(중심·각도·길이·너비)로 크기를 바로 바꿉니다.
- 텍스트: 내용, 스타일, 정렬(왼쪽·가운데·…·하단 오른쪽, 기준점은 그대로), 높이, 회전, 너비(폭) 인자, 경사각, 위치, 역방향·뒤집기. MText: 정렬, 텍스트 높이, 회전, 줄 간격 인자·거리·스타일, 배경 마스크, 정의된 너비·높이.
- 블록 참조: 위치·축척(속성 문자도 같이 움직임), 이름(다른 블록으로 바꾸기), 회전, 속성 값. 해치: 패턴 이름, 각도, 축척, 섬 감지 스타일, 고도, 면적.
- 치수: 기타(치수 스타일 바꾸기), 선 화살촉(화살촉 1·2, 화살촉 크기, 치수선·연장선 선 두께·켜짐/꺼짐·색상·선종류, 연장선 연장·간격띄우기·고정 길이), 텍스트(채우기 색상, 텍스트 색상·높이·간격띄우기, 위치 수평·수직, 텍스트 스타일, 위치 X/Y, 회전, 재정의), 맞춤, 기본 단위, 대체 단위, 허용 오차. 여기서 바꾼 값은 그 치수에만 저장되고(치수 스타일 재정의, 기존 CAD와 같은 DSTYLE 형식) 기존 CAD에서도 같은 값으로 보입니다. 스타일과 같은 값으로 되돌리면 재정의가 지워집니다.

## 치수 모양 (기존 CAD와 같음)
- 치수 문자는 치수선과 겹치지 않습니다: 수평 치수는 치수선 위에(간격 + 글자 높이의 절반), 수직 치수에 수평 문자는 치수선 가운데에 두고 그 자리만큼 선을 끊습니다(치수 스타일 "텍스트 위치 수직"·"텍스트 내부/외부 정렬"을 따름).
- 보조선 사이가 좁아 화살촉이 안 들어가면 화살촉을 밖으로 두고(보조선을 가리킴) 짧은 선을 긋습니다. 문자도 안 들어가면 밖에 두며, 수직 치수는 짧은 선 끝의 수평 받침선 위에 둡니다(맞춤: 최적 맞춤).
- 문자 그립·DIMTEDIT로 문자를 옮기면 "치수선과 텍스트 이동" 스타일에서는 치수선도 함께 옮겨집니다.
- 반지름·지름 치수 문자가 원 밖에 있으면 화살촉 → 짧은 지시선 → 수평 받침선 → 문자로 그립니다.
- 이전 버전에서 만든 치수는 DIMREGEN(모든 치수 다시 그리기, Ctrl+Z로 되돌리기)을 하거나 속성·그립으로 고치면 새 모양이 됩니다.

## 속성창 — 여러 개·그 밖의 객체 (기존 CAD와 같음)
- 같은 종류를 여러 개 고르면 기하학·텍스트 등 항목이 그대로 나오고, 값이 다르면 *다양함*으로 보입니다. 값을 넣으면 고른 객체 모두에 한 번에 적용되고 Ctrl+Z(U) 한 번으로 되돌아갑니다.
- 종류가 섞이면 위쪽 목록(All (n), 선 (2) …)에서 종류를 고르면 그 종류만의 항목이 나오고, 그 종류에만 적용됩니다.
- 스플라인(맞춤점·조정점 번호와 X/Y/Z, 차수·닫힘 등), 구성선·광선(기준점·두 번째 점·방향 벡터), 다중선(스타일·정렬·축척 — 정렬·축척을 바꾸면 요소 간격을 다시 계산), 지시선(꼭짓점, 치수 스타일, 유형, 화살촉·크기·색·선두께, 문자 간격·위치, 전체 축척 — 그 지시선에만 재정의), 다중 지시선(전체 축척, 화살촉 크기, 랜딩 거리, 내용·정렬·폭·높이·줄 간격), 표(높이·너비, 위치, 행·열 추가/삭제), 솔리드(꼭짓점, 고도), 속성 정의(태그·프롬프트·값·스타일·정렬·높이 …, 보이지 않음·상수·검증·사전 설정·위치 잠금), 와이프아웃(위치·회전·너비·높이, 이미지·클리핑 표시)도 기존 CAD와 같은 항목으로 바꿀 수 있습니다.
- 하이퍼링크: 일반 분류의 하이퍼링크 칸에 주소를 넣습니다(기존 CAD와 같은 형식으로 저장, 비우면 지움). 해치: 배경 색상을 고르면 패턴 아래가 그 색으로 채워집니다.
- 표: 선택하면 기존 CAD와 같은 그립이 나옵니다 — 왼쪽 위(이동), 위쪽 열 경계(그 열 너비), 오른쪽 위(전체 너비), 왼쪽 아래(전체 높이), 오른쪽 아래(너비·높이 함께). 끌어서 크기를 바꿉니다.
- 와이프아웃은 테두리가 보이면 테두리를 클릭해 고를 수 있습니다.

## 치수 스타일 (DIMSTYLE)
- 수정 창의 모든 탭 값이 "확인" 때 스타일에 저장되고, 그 스타일을 쓰는 치수가 바로 다시 그려집니다 (Ctrl+Z로 되돌리기). Alternate Units(대체 단위)·Tolerances(허용 오차) 탭도 기존 CAD와 같은 항목으로 쓸 수 있습니다.

## 그리기·수정 명령 문구 (기존 CAD와 같음)
- LINE: Enter = 마지막 점에서 시작, 각도(A) "선의 각도:" → "선 길이:", 길이(L), 따라가기(F, 앞 선 방향으로 길이만), 닫기(C), 취소(U).
- PLINE: 시작에서 Enter = 마지막 점. 거리(D) "세그먼트 거리/각도", 너비(W)·반폭(H)은 시작·끝 폭을 따로(가늘어지는 조각), 따라가기(F). 호 모드: 각도(A)·중심(CE)·방향(D)·반지름(R)·두번째점(S)·선그리기(L)·닫기(CL). 새 폴리선의 기본 폭은 도면의 PLINEWID입니다(기존 CAD와 같음).
- MOVE: "기준점 또는 [거리(D)]", 두 번째 점에서 Enter = 첫 점을 변위로. COPY: 모드(O, 단일/다중), 배열(A, 개수 → 간격 또는 맞춤 F), 취소(U), 종료(E).
- ROTATE: 복사(C), 기준각도(B → 새 각도, 점 P). SCALE: 기준점(B), 복사(C), 참조(R → 새 길이, 점 P). MIRROR: "원래 객체를 삭제합니까? <N>".
- OFFSET: 통과점(T), 지우기(E, 원본 지우기), 도면층(L, 현재/원본), 양쪽(B), 취소(Undo). 폴리선은 모서리를 만나는 점까지 이어 줍니다(호 조각 포함).
- TRIM·EXTEND: 모서리모드(E: Extend면 경계를 늘린 것으로 봄), 울타리(F: 그은 선이 지나는 객체를 한 번에), 투영(P), 취소(U).
- 객체 선택에서 L = 마지막에 만든 객체, P = 직전 선택, ALL = 전부. 고를 때 "세트 내의 객체: N", 끝낼 때 "N 찾음"이 나옵니다.
- 숫자만 입력하면 명령이 값(각도·배율·개수)을 묻는 중이면 그 값으로, 점을 묻는 중이면 커서 방향으로 그 거리만큼(직접 거리)으로 받습니다.
- RECTANG: 모따기(C)·모깎기(F)·너비(W)·높이(E)·두께(T)는 도면의 다음 사각형에도 그대로, 회전(R)·정사각형(S)은 이번만. 두 번째 구석에서 면적(A)·치수(D)·회전(R).
- ARC: 시작에서 Enter = 마지막 선·호 끝에 접하는 호. 두 번째 점 단계에서 각도(A)·중심(C)·방향(D)·끝(E)·반지름(R).
- ELLIPSE·POLYGON: 기존 CAD 문구, POLYGON 다중(M)·너비(W), 내접/외접 기본값은 마지막 선택(처음은 외접 C).
- BREAK: 선·호·원·폴리선, "두번째 끊기점 지정 or [첫번째점(F)/분할(S)]".
- LIST: 기존 CAD처럼 핸들·현재 공간·도면층·색상·선종류·선두께와 객체별 값(시작점·끝점·길이·델타, 면적, 위치 등)을 줄마다 보여 줍니다.
- CHAMFER: 첫 선을 고르기 전 Enter는 현재 설정을 다시 보여 줍니다(기존 CAD와 같음, 끝내려면 Esc).
- HATCH: 내부 점으로 찾은 경계와 객체 선택으로 고른 경계가 점선으로 보입니다(기존 CAD와 같음).
- TEXT: "텍스트의 시작점을 지정 or [정렬(J)/Style]" → 높이 → 회전 → 그 자리에서 입력. Enter = 다음 줄, 빈 줄에서 Enter = 끝. 정렬은 TL·MC·BR 등 15가지와 Align·맞춤.
- XLINE·RAY: 이등분·수평·수직·각도(참조)·간격띄우기(거리 또는 통과점). POINT는 점 하나(다중 M이면 여러 개, 리본 "다중 점"은 다중). SPLINE은 점을 다 찍은 뒤 시작·끝 접선을 묻습니다(Enter = 자동).
- DONUT·DIVIDE·DIMLINEAR: 기존 CAD 문구, 치수 뒤 "치수 텍스트 = 값" 표시.
- BLOCK(B): 기존 CAD와 같은 "블록 정의" 대화상자 — 이름·설명, 기준점(화면에서 지정·기준점 선택·X/Y/Z), 객체(화면에서 지정·객체 선택·유지/블록으로 변환/삭제), 동작(주석·균일한 축척·분해 허용·단위). 같은 이름이면 다시 정의합니다. 명령줄 방식은 -BLOCK.
- INSERT(I): "블록 삽입" 대화상자 — 파일(From file) 또는 블록 이름, 삽입 지점·축척(동일한 축척)·회전(화면에서 지정), 블록 단위, 미리보기, 분해. 화면에서 지정이면 "블록의 삽입점" → X 축척 → (Y 축척) → 회전 → 속성 값. 명령줄 방식은 -INSERT.
- DIMRADIUS·DIMDIAMETER: 각도(A)·Mtext·텍스트(T) 옵션, 현재 치수 스타일, 문자는 놓은 곳에, 화살촉과 지시선이 기존 CAD와 같습니다. DIMCONTINUE·DIMBASELINE 문구도 같습니다.
- ARRAY: "ARRAY 객체 선택:", 시작할 때 "Type = 직사각형(R)  Associative = 예(Y)" 표시. MEASURE: "세그먼트 길이 [블록(B)]".
